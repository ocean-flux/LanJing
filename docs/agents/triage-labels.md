# Triage 标签

工程技能使用下列五个 canonical triage role。`Status:` 字段写入右列的字符串。

| Canonical role | 本仓库字符串 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚未判断事项。 |
| `needs-info` | `needs-info` | 等待补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 agent 实施。 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或决策。 |
| `wontfix` | `wontfix` | 明确不处理。 |
