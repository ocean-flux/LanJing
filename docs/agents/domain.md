# 领域文档

本仓库使用单上下文领域文档。

## 开始工作前

- 阅读根 `CONTEXT.md`。
- 阅读与当前改动相关的 `docs/adr/`。
- 文件不存在时静默继续；只有 `/domain-modeling` 在术语或决定实际形成时创建它们。

## 术语

事项标题、规格、测试名和设计讨论必须使用 `CONTEXT.md` 已定义的词。不要使用其中明确列为 `_Avoid_` 的同义词。

需要但未定义的词应先判断是否只是实现术语；确有领域缺口时，通过 `/domain-modeling` 补充。

## ADR 冲突

与现有 ADR 冲突时必须显式说明冲突和重新审议的原因，不能静默改写既有决定。
